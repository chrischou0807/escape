# escape — 機關範例庫

校園密室／闖關活動用的互動機關範例庫。首頁彙整各式機關，每個機關都是**獨立的單檔 HTML 網頁**，繁體中文介面、手機／平板可直接觸控操作，離線也能跑。

線上版（GitHub Pages）：`https://chrischou0807.github.io/escape/`

---

## 結構

- `index.html` — 首頁（範例庫）。長按右上角齒輪 → 進首頁後台，可新增／修改／刪除／排序機關、匯出入設定、設定程式碼分享。
- `teach/index.html` — 教學頁：**用 AI 做出這些機關**（給學生自學，含「規格 → 提示詞產生器」與簡報模式）。
- `teach/slides_puzzles.html` — **謎題設計簡報**：從《神奇修護師》20 題拆出六種設計手法（變形與還原、拆字組字、編碼查表、歸納規則、空間路徑、觀察干擾），每種附一款新範例（No.140–145），最後談提示、難度與如何套進機關。方向鍵或點畫面換頁。
- `template/index.html` — 空白機關起手骨架（共用外殼已備好，找 `✏️` 標記填入玩法）。
- `workbench/index.html` — **機關設計工作台**：把知識點拆解成機關，產生給 AI 的提示詞，再貼回檢查與預覽；內含 162 款機關的範例庫（六玩法下再分形式）。
  - `workbench/engine.html` — 第二條線（3D 密室）的關卡引擎，工作台用它載入與試玩關卡 JSON。
  - `workbench/ex/*.html` — 範例庫新增的 144 款精簡機關（No.13–156；含拖曳吸附拼圖 jigsaw.html）。
  - `workbench/ex-src/` — No.101–156 的原始檔：`shell.html` 是共用外殼，`games_*.js` 是各機關的玩法，`python3 build.py` 把兩者合成單檔（輸出到 `out/`，再複製到 `workbench/ex/`）。這 56 款的後台用一個 JSON 文字框編輯題目內容。

## 故事版：神奇修護師《缺頁的病歷表》

`restorer/index.html` 是一個完整的線上故事解謎，把《神奇修護師》的 20 道謎題用一個故事串起來：駐館修護師失聯，她的修護紀錄（文物的病歷表）被撕掉二十頁，玩家要在特展開幕前一頁一頁找回來。

- 六章，依真實的修護流程排列：認識修護師 → 檢視登錄 → 各項測試 → 工具 → 補色與判斷 → 結局。
- 開始時選木質、紙質或陶瓷修護師。和自己專長有關的題目會直接看到「專業直覺」，其他題目的第一個提示要問隊友或花一次提示機會，適合小組各選一種角色。
- 每解開一題，會找回一頁病歷表，並附一則修護知識。進度存在瀏覽器裡，可以分次玩。
- 結局前要排出修護五步驟，最後有一題沒有標準答案的抉擇。

網址：<https://chrischou0807.github.io/escape/restorer/>

### 第二個故事：《日記的主人》

`restorer/diary/index.html` 用同樣的 20 道謎題，換成以文物為主角的故事：博物館收到一本沒有署名的日記，內頁用膠帶貼滿幸運草。玩家一邊修，一邊從每次檢測與修護的發現拼出日記主人的故事，最後排出事件的先後，並決定要把它修回哪個時期的樣貌。

網址：<https://chrischou0807.github.io/escape/restorer/diary/>

## 共用功能（每個機關都有）

- **後台**：長按右上角齒輪 0.6 秒 → 輸入後台密碼（**預設 `9633`**）→ 進入設定。玩家看不到後台。
- **揭曉卡**：過關後顯示線索文字／圖片（圖片可點擊放大）。
- **音效**：Web Audio，可在後台關閉。
- **記憶**：設定存在該裝置的瀏覽器（localStorage）。
- **可嘗試次數**：No.05、13、21、22、58、66、67、75、111 有次數限制，用完會重來，避免靠亂試過關。05 在後台設定，111 改 JSON 裡的 `checks`，其餘改檔案開頭 `CFG` 的 `tries`（75 是 `moves`）。
- **錯誤的代價與引導**：No.24、49、62、89、100、103、114 讓亂試有代價（後段變嚴、條件要答題才解鎖、開火前要答題、干擾答案）；No.09、52 放錯時給一句引導思考的提示，不直接給答案。
- **產生分享連結**：後台可把「目前設定」編碼成一條獨立網址（`?c=...`）。同一個機關可重複用於不同遊戲——各自產生一條連結即可，不需後端。
  - 注意：分享連結內含設定（含答案），適合課堂使用；要隱藏答案才需要後端。
  - 上傳的圖片會讓網址過長，分享時請改用「圖片網址」。

## 需要注意的機關（語音相關）

- **No.10 電話撥號 / No.11 密室收音機**：語音用裝置的「語音合成（TTS）」直接把文字唸出來，品質與有無中文聲音**因裝置而異**；要最穩就在後台改放「音檔網址」的預錄語音。收音機若語音沒出聲，會自動顯示字幕當答案。
- **No.12 咒語**：使用瀏覽器「語音辨識（Web Speech API）」。
  - 必須在 **https 網站**上執行（GitHub Pages 沒問題），並允許**麥克風權限**。
  - 支援度：**Chrome／Edge／Android 最佳；Firefox 不支援；iOS Safari 視版本而定**。（多數線上預覽視窗無法用麥克風，請到實際部署網址、用 Chrome 測。）
  - 不支援或權限被拒時，畫面會自動提供**「改用打字」**後援，任何裝置都能過關。

## 範本：做一個新機關

`template/index.html` 已備好全部共用外殼（齒輪／後台／揭曉卡／音效／分享連結）。複製後找 `✏️` 標記，填入四個部分：設定（cfg）、正規化（normalize）、畫面建立（build）、過關判定（solve）。

## 新增機關到首頁

1. 在 `<名稱>/index.html` 放該機關的單檔網頁。
2. 首頁後台「新增機關」，連結填 `<名稱>/`，狀態設「可遊玩」。
3. 要讓所有人都看到：用首頁後台「匯出設定」，把內容貼回 `index.html` 的 `DEFAULT_HUB` 後重新上傳。
